LOTEO SAN LORENZO - página web (index.html)

SUBIR A GITHUB
1. Creá un repositorio nuevo en GitHub (público).
2. Subí el archivo index.html a la raíz del repositorio (Add file > Upload files).
3. Settings > Pages > Source: "Deploy from a branch" > Branch: main / (root) > Save.
4. En un minuto tenés el link: https://TU-USUARIO.github.io/NOMBRE-DEL-REPOSITORIO/

PLANILLA (disponibilidad en vivo)
- La página lee la planilla de Google Sheets "Loteo San Lorenzo - Lotes" (pestaña "Lotes") cada vez que se abre y cada 60 segundos mientras se ve el plano.
- Compartí la planilla como EDITOR solo con tu cliente (por email).
- Para que la página pueda leerla, en Compartir > Acceso general elegí "Cualquier persona con el enlace" con permiso de LECTOR.
- Columnas que lee la página: A Lote, B Superficie, C Frente, D Fondo, F Precio, H Disponibilidad (Disponible / Reservado / No disponible). No cambies el orden de las columnas ni el nombre de la pestaña ni los números de lote.
- Si la planilla no responde, la página muestra los últimos datos guardados en el archivo.
